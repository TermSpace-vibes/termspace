# Home View Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make Home — pinned + recently-used workspace cards, plus "New Workspace" — the mandatory first screen on every launch, replacing today's silent auto-jump into the last/first workspace's terminal grid.

**Architecture:** `showHome` is local, unpersisted `App.tsx` state defaulting to `true`, rendered as an absolute-positioned overlay above the existing (unchanged) workspace-view stack — the same pattern the loading screen already uses. A new shared store action, `touchWorkspaceLastOpened`, is the single place that writes the new `last_opened_at` DB column and optimistically patches the in-memory `workspaces` array, used by boot, the sidebar, and Home alike. Card ordering and the two must-fix interaction issues (native webview bleed-through, stray DOM focus) are handled per the spec.

**Tech Stack:** React 19 + TypeScript, Zustand, Rust/Tauri + rusqlite, Vitest + Testing Library.

**Spec:** `docs/superpowers/specs/2026-09-02-home-view-design.md`

## Global Constraints

- No `App.test.tsx` exists and this plan does not add one — `touchWorkspaceLastOpened` is extracted into the store specifically so its behavior is unit-testable without mounting `App.tsx`.
- `showHome` must be included in `App.tsx`'s `isAnyModalOpen` computation (`App.tsx:82`) — this is not optional; skipping it lets a background workspace's native browser-pane webview render on top of Home regardless of CSS `zIndex`.
- `HomeView` must steal DOM focus on mount — otherwise a hidden terminal pane underneath can retain keyboard focus and swallow keystrokes meant for Home.
- Pinned workspaces on Home preserve their existing array order (matching the sidebar's established convention); only the non-pinned bucket is sorted by `lastOpenedAt` descending (falling back to `createdAt` when null).

```tsx
// src/components/Home/HomeView.tsx
import { useEffect, useRef } from 'react'
import type { Workspace } from '../../types'

interface Props {
  workspaces: Workspace[]
  onSelectWorkspace: (id: string) => void
  onNewWorkspace: () => void
}

export function sortWorkspacesForHome(workspaces: Workspace[]): { pinned: Workspace[]; recent: Workspace[] } {
  const pinned = workspaces.filter((w) => w.isPinned)
  const recent = workspaces
    .filter((w) => !w.isPinned)
    .slice()
    .sort((a, b) => (b.lastOpenedAt ?? b.createdAt) - (a.lastOpenedAt ?? a.createdAt))
  return { pinned, recent }
}

export function HomeView({ workspaces, onSelectWorkspace, onNewWorkspace }: Props) {
  const newWorkspaceButtonRef = useRef<HTMLButtonElement>(null)

  useEffect(() => {
    newWorkspaceButtonRef.current?.focus()
  }, [])

  const { pinned, recent } = sortWorkspacesForHome(workspaces)
  const ordered = [...pinned, ...recent]

  return (
    <div
      style={{
        position: 'absolute', inset: 0, zIndex: 100,
        background: 'var(--bg-main)', display: 'flex', flexDirection: 'column',
        alignItems: 'center', padding: '48px 24px', overflowY: 'auto',
      }}
    >
      <button
        ref={newWorkspaceButtonRef}
        onClick={onNewWorkspace}
        style={{
          padding: '10px 20px', background: 'var(--accent)', border: 'none', borderRadius: 8,
          color: 'var(--bg-main)', fontSize: 14, fontWeight: 600, cursor: 'pointer', marginBottom: 32,
        }}
      >
        + New Workspace
      </button>

      <div style={{ display: 'grid', gridTemplateColumns: 'repeat(auto-fill, minmax(200px, 1fr))', gap: 16, width: '100%', maxWidth: 900 }}>
        {ordered.map((ws) => (
          <button
            key={ws.id}
            onClick={() => onSelectWorkspace(ws.id)}
            style={{
              display: 'flex', flexDirection: 'column', alignItems: 'flex-start', gap: 8,
              padding: 16, borderRadius: 10, cursor: 'pointer', textAlign: 'left',
              background: 'var(--bg-sidebar)', border: `1px solid ${ws.isPinned ? 'var(--accent)' : 'var(--border-inactive)'}`,
            }}
          >
            <span style={{ fontSize: 24 }}>{ws.emoji}</span>
            <span style={{ fontSize: 14, fontWeight: 600, color: 'var(--text-active)' }}>{ws.name}</span>
          </button>
        ))}
      </div>
    </div>
  )
}
```
